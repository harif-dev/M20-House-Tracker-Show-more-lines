M20 House Tracker prototype

This is a local-first Progressive Web App prototype created from M20_Direct_Roof_Master_Checklist.xlsx.

Files: index.html, app.js, style.css, data.js, manifest.json, sw.js.

Progress, checklist ticks and site notes are stored in the browser on the device. Clearing browser/site storage will remove those records.

For installable phone use, host these files on an HTTPS web host. Then open the HTTPS address in a supported browser and use its install/add-to-home-screen option.
